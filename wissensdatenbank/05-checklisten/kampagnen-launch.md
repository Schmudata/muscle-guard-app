# Checkliste: Neue lokale Google-Ads-Kampagne starten

## Vorbereitung (mit dem Kunden klären)
- [ ] Welche Leistungen sollen beworben werden – und welche sind am profitabelsten?
- [ ] Einzugsgebiet (Orte/PLZ/Radius), Orte, die **nicht** bedient werden
- [ ] Erreichbarkeit (Telefonzeiten), Kapazität (wie viele Aufträge pro Woche?)
- [ ] Ø Auftragswert, Marge, Abschlussquote → Ziel-CPL ([Formel](../04-digital-marketing/budgetplanung-kpis.md))
- [ ] Monatsbudget
- [ ] USPs, Bewertungen, Zertifikate, Fotos
- [ ] Wer bearbeitet Leads – und wie schnell?

## Fundament
- [ ] Google Unternehmensprofil vollständig & verifiziert
- [ ] Landingpage(s) je Leistung, mobil getestet
- [ ] Tracking: Formular, Anrufe, Telefonklick; Consent Mode; Test-Conversion
- [ ] GA4 & GBP mit Google Ads verknüpft

## Kampagne
- [ ] Kampagnentyp Suche, nur Google-Suche (Display aus)
- [ ] Standort + Option „Präsenz“, Sprache Deutsch (+ ggf. Englisch)
- [ ] Werbezeitplan
- [ ] Gebotsstrategie für den Start (manuell / Klicks max. mit Obergrenze / Conversions max.)
- [ ] Anzeigengruppen je Leistung, Keywords Phrase/Exact
- [ ] Negative-Keyword-Listen angewendet
- [ ] RSA mit 10–15 Titeln, 4 Beschreibungen, Ort im Text
- [ ] Assets: Sitelinks, Callouts, Snippets, Anruf, Standort, Bilder, Logo
- [ ] Finale URLs geprüft (keine 404, UTM/Auto-Tagging aktiv)

## Nach dem Start
- [ ] Tag 1–2: Anzeigen genehmigt? Ausspielung? Klicks?
- [ ] Tag 3–7: Suchbegriffe säubern, erste Conversions geprüft
- [ ] Woche 2–4: Gebote/Budgets nachjustieren, Lead-Qualität mit Kunde besprechen
- [ ] Nach 4–6 Wochen: Gebotsstrategie-Stufe prüfen ([Gebotsstrategien](../01-google-ads/gebotsstrategien.md))
