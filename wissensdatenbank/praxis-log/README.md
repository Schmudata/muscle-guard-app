# Praxis-Log

Hier landen **eigene Beobachtungen, Tests und Zahlen** aus echten Konten und Projekten. Das ist
der wertvollste Teil der Datenbank:
- **Lernen:** Wissen wird erst durch eigene Erfahrung belastbar.
- **Perspektiven:** Eigene Daten widersprechen manchmal der Lehrmeinung, und genau das ist interessant.
- **Blog:** Eigene Erfahrungen und Zahlen kann niemand kopieren. Sie sind die Grundlage für
  glaubwürdige Artikel (E-E-A-T: Experience, Expertise, Authoritativeness, Trust).

## Regeln
- **Anonymisieren:** keine Kundennamen, keine personenbezogenen Daten; Branche + Region + Budgetklasse reichen.
- **Nur echte Beobachtungen.** Vermutungen als solche kennzeichnen.
- Ein Eintrag pro Datei: `JJJJ-MM-TT-kurzes-thema.md`, Vorlage: [_vorlage.md](_vorlage.md).
- Kurz ist okay: 5 Zeilen am selben Tag sind besser als ein perfekter Eintrag, der nie geschrieben wird.
