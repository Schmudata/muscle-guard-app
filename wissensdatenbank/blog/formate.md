# Blogformate & Gliederungsvorlagen

Jedes Format braucht **eine Kernthese** und **etwas Eigenes**: eine Zahl, eine Beobachtung, eine
Meinung oder ein Beispiel aus dem [Praxis-Log](../praxis-log/). Reines Lehrbuchwissen gibt es
überall, und KI-Antworten liefern es inzwischen direkt.

## 1. Anleitung (How-to)
1. Problem in einem Satz + für wen der Artikel ist
2. Ergebnis vorwegnehmen („Nach diesem Artikel können Sie …“)
3. Schritte (nummeriert, je mit Screenshot/Beispiel)
4. Häufige Fehler
5. Checkliste zum Mitnehmen
6. CTA (Beratung, Audit, Newsletter)

## 2. Fallstudie
1. Ausgangslage (Branche, Ort, Budget, Problem – anonymisiert)
2. Ziel und Messgröße
3. Was wir gemacht haben (Entscheidungen + Begründung)
4. Ergebnisse mit Zahlen (vorher/nachher, Zeitraum)
5. Was nicht funktioniert hat
6. Übertragbare Lektionen

## 3. Meinung / Gegenthese
1. Verbreitete Annahme („Alle sagen …“)
2. Die eigene These („Wir sehen das anders, weil …“)
3. 3 Argumente mit Belegen/Erfahrung
4. Fairer Blick auf die Gegenseite ([Streitfragen](../README.md) in den Artikeln nutzen)
5. Wann die eigene These nicht gilt
6. Fazit + Frage an die Leser

## 4. Checkliste / Liste
1. Warum diese Liste wichtig ist
2. Punkte gruppiert (je 1–3 Sätze + Beispiel)
3. Priorität markieren („Wenn Sie nur 3 Dinge tun …“)
4. Download/Vorlage anbieten

## 5. „Wir haben X getestet“
1. Hypothese
2. Testaufbau (Zeitraum, Budget, Messung)
3. Ergebnis – auch wenn es negativ ist
4. Einordnung: Zufall oder Muster?
5. Empfehlung

## 6. Trend-Einordnung
1. Was ist neu? (Quelle, Datum)
2. Was bedeutet es für einen Betrieb mit 1.000 €/Monat?
3. Jetzt handeln, testen oder beobachten? (Bezug zum [Trendradar](../07-trends/trendradar.md))
4. Konkreter nächster Schritt
